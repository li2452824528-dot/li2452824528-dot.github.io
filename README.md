# Weihan Li Portfolio

An English, static portfolio for GitHub Pages. The page uses plain HTML, CSS, and JavaScript so it can be hosted directly without a build step.

Live site: `https://li2452824528-dot.github.io/`

## Site structure

- `index.html` contains the approved English content and accessible document structure.
- `enhancements.css` adds the responsive visual system, project stages, and reduced-motion behavior.
- `app.js` adds the scroll progress indicator, active navigation, and project interactions.
- Repository evidence is integrated directly into Selected Work and More Projects rather than repeated in a standalone section.

## Publish with GitHub Pages

1. The personal-site repository is `li2452824528-dot.github.io`.
2. Put the contents of this folder at the repository root, including `.github/workflows/pages.yml`.
3. In the repository, open **Settings > Pages** and choose **GitHub Actions** as the publishing source.
4. Push the files to the `main` branch. The workflow will deploy the site; follow its run under **Actions**.

The workflow can also be started manually from the Actions tab.
